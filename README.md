# Karaoke TV

Ранняя версия караоке-приложения для Android TV и смартфонов на Kotlin/Compose. Минимальная версия Android — 9 (API 28).

[Последний релиз](https://github.com/KachalovBalera/Karaoke-TV-Codex/releases/latest) · [Скачать karaoke-tv.apk](https://github.com/KachalovBalera/Karaoke-TV-Codex/releases/latest/download/karaoke-tv.apk)

Доступны очередь, избранное, история, адаптивная навигация и экспериментальный поиск RUTUBE без ключа. YouTube/VK требуют ключа/токена; в публичном APK они отсутствуют, пользовательская настройка пока не реализована. Сквозные проверки на устройствах не завершены. Не считать приложение полностью готовым.

Обновления проверяются при запуске и вручную в настройках через публичный GitHub Releases API без GitHub-токенов. Загрузка показывает прогресс; перед передачей системному установщику проверяются SHA-256, версия, applicationId и сертификат. Разрешение на установку и окончательное подтверждение даёт пользователь. Работа всей цепочки на TV/телефоне ещё требует проверки.

Release-сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Release.ps1`. Ключ остаётся вне Git; правила резервного копирования — [SIGNING.md](docs/SIGNING.md). Публикация вручную, только по команде владельца; сборка ничего не загружает.

## Матрица технической реализуемости

| Возможность | YouTube | VK Видео | RUTUBE |
|---|---|---|---|
| Поиск | Да, YouTube Data API v3 `search.list` | Да, `video.search` при доступной авторизации/API | Доступность зависит от официального API/партнёрского доступа; нельзя считать неофициальные endpoints контрактом |
| Метаданные | Да, `videos.list` | Да, `video.get`/oEmbed | Да, официальные play options для доступных параметров |
| Встроенный плеер | Да, официальный IFrame embed | Да, официальный embed/oEmbed сценарий; не прямой Media3 stream | Да, официальный iframe embed |
| Управление | Ограничено API embed; качество выбирает сервис | Ограничено embed-плеером | postMessage-команды и события, включая завершение/ошибки |
| Определение окончания | События IFrame API | Зависит от embed-интеграции; резерв — ручное продолжение | `player:playComplete` |
| Android TV | Через WebView/embed или официальный внешний клиент | Через WebView/embed или внешний клиент | Через WebView/embed или внешний клиент |

Приложение не извлекает скрытые потоковые URL, не обходит DRM и не маскирует локальные оценки под глобальный рейтинг. Если сервис не даёт разрешённый встроенный запуск, интерфейс предлагает открыть официальный внешний плеер.

## Сборка

Откройте каталог в Android Studio с JDK 17. API-ключи и токены источников должны передаваться через `local.properties`/секретное хранилище и не коммититься.

Для проверки из PowerShell используйте `./gradlew.bat test`, а для APK — `./gradlew.bat assembleDebug`. Проект использует Gradle Wrapper 8.11.1 и Android Build-Tools 35.0.0.

Подробная инструкция и ограничения сборки находятся в [docs/APK.md](docs/APK.md).

Для первого адаптера YouTube можно передать ключ только локально при сборке: `./gradlew assembleDebug -PyoutubeApiKey=ВАШ_КЛЮЧ`. Ключ не должен попадать в Git. Без ключа YouTube-адаптер возвращает явную ошибку конфигурации.

Для локальной debug-сборки VK Видео можно настроить через Gradle properties. Release-сборка принудительно исключает ключи YouTube/VK из APK. RUTUBE использует экспериментальный публичный endpoint, стабильность которого не гарантируется.

Локальное управление использует случайный гостевой токен и отдельный административный токен. Сервер предназначен только для домашней сети; публичная публикация порта не поддерживается.

Во время выступления приложение может запросить `RECORD_AUDIO` и показать техническое качество микрофонного сигнала. Этот показатель не является автоматической экспертной оценкой вокала; без разрешения микрофона выступление и история остаются доступными, но технический балл не записывается.
