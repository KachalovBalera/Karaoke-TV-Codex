# Karaoke TV 1.0.0

Первый подписанный релиз проекта Codex для Android 9+ и Android TV.

- Адаптивная навигация, поиск, очередь, избранное и история.
- Экспериментальный поиск RUTUBE без ключа; доступность зависит от сервиса.
- Официальные адаптеры YouTube и VK требуют авторизации. В публичный APK ключи не включены; пользовательская настройка этих ключей ещё не реализована.
- Встроенные плееры, LRC при наличии таймкодов, технический монитор микрофонного сигнала.
- Проверка обновлений при запуске и в настройках, SHA-256 и проверка сертификата перед передачей APK установщику.

Ограничения: сквозная установка обновления и воспроизведение на физических устройствах не проверены. HTTP-проверка RUTUBE не подтверждает работу видео на каждом устройстве. Это ранняя версия; наличие функций в сборке не является подтверждением полной готовности.

APK подписан отдельным постоянным release-ключом. Он не обновит debug-сборку с другой подписью. Сохраните нужные данные перед сменой установки; приложение не выполняет автоматическое удаление данных.
