# Release-подпись

Запуск: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Release.ps1`.

Ключ: `%LOCALAPPDATA%/Karaoke-TV-Codex-Signing/release.p12`, alias `karaoke-tv`. Пароль хранится рядом в `password.dpapi`, зашифрован Windows DPAPI для текущего пользователя. Каталог имеет ограниченный ACL. Пароль не передаётся в аргументах команд и не печатается. Скрипт не публикует файлы и повторно использует постоянный ключ.

Обязательно сделайте независимую зашифрованную резервную копию ключа и пароля в менеджере паролей. Файл DPAPI сам по себе не является переносимой резервной копией: после утраты профиля Windows расшифровка может стать невозможной. Не удаляйте ключ и не создавайте вместо него новый для обновлений существующей установки.

Выпуск следующих релизов разрешён только командой «ОПУБЛИКОВАТЬ ОБНОВЛЕНИЕ KARAOKE TV». Автопубликации и CI-upload нет.
