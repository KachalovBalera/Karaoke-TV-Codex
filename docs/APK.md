# Подготовка APK

## Локальная сборка

1. Установить JDK 17 и Android SDK с API 35 и Build-Tools 35.0.0.
2. Скопировать `local.properties.example` в `local.properties` и заполнить только нужные ключи локально.
3. Запустить `.\gradlew.bat assembleDebug`.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Для релизной публикации необходимо отдельно настроить защищённое signing-хранилище. Ключи источников не должны попадать в Git или в публичный APK-репозиторий.

Текущая среда не позволяет подтвердить сборку: Maven-зависимости отсутствуют в offline-кэше, а предыдущая онлайн-загрузка зависла. Повторная попытка без изменения окружения запрещена рабочим процессом.
